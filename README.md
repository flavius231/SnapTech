# SnapTech - Hardware Infrastructure & Security

SnapTech is a web platform developed to offer premium infrastructure services (Bare-Metal, DBaaS) and hardware security audit. The project represents the exact combination of high-performance computing power and absolute cybersecurity at the transistor level.

## Main Features

* **Minimalist Design & Bento Grid:** A modern user interface (UI) with fluid animations, mathematically calculated asymmetry, created without external frameworks (Vanilla HTML/CSS/JS).
* **Knowledge Hub & Dynamic Filtering:** Integrated system for sorting technical resources and equipment.
* **Authentication System (Full-Stack):** Complete Registration/Login flow connected directly to the database.
* **Appointment Management:** Retrieving client data and securely storing it on the server, including notifying them via Gmail regarding the appointment to contact us.

## Technologies Used

**Front-end:**
* HTML5 (Semantic structure)
* CSS3 (Flexbox, CSS Grid, Glassmorphism and Parallax effects)
* JavaScript (Vanilla JS for filtering logic and scroll animations)

**Back-end & Database:**
* Node.js (Application server - `server.js`)
* MySQL (Management of `utilizatori` and `programari` tables)
* API integration and asynchronous communication with the front-end (Fetch API)
